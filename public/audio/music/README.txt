OPTIONAL BACKGROUND TRACK
=========================

Valor Forged is configured to look for:

    public/audio/music/dark-aria.mp3

The requested commercial track is NOT bundled with this repository.
Only place an audio file here if you have the legal right/licence to use it.
If dark-aria.mp3 is absent, the game automatically uses its built-in original
procedural dark-cinematic music bed instead.
